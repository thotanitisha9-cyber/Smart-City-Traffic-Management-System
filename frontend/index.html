Dynamic Edge Weight Formula

Dynamic Cost = Distance (km) × Traffic Multiplier
  • LOW: Multiplier 1.0x (Standard flow)
  • MEDIUM: Multiplier 1.5x (Moderate queuing)
  • HIGH: Multiplier 2.5x (Heavy bottleneck)
  • SEVERE: Multiplier 4.0x (Severe congestion)
  • BLOCKED: Cost = ∞ (Link pruned / avoided)

Viva Question Highlight:

Q: Why is Dynamic Routing superior to Static Shortest Path Routing?

A: Static routing uses fixed distances, which leads to heavy packet queuing and bottleneck drops whenever a link gets congested. Dynamic routing monitors real-time link states (traffic density) and recalculates the least-cost path, effectively balancing load across alternative under-utilized channels.

Dijkstra's Algorithm Implementation

Algorithm Overview

Dijkstra's Shortest Path Algorithm is a greedy single-source shortest path algorithm that finds the minimal cost route in a graph with non-negative edge weights.

  1. Initialization: Set distance to source node $dist[src] = 0$. For all other vertices $v$, set $dist[v] = \infty$. Initialize predecessor map $prev[v] = \text{null}$.
  2. Priority Queue: Insert $(0, src)$ into a min-heap priority queue.
  3. Vertex Selection: Extract vertex $u$ with minimum tentative distance from the priority queue.
  4. Edge Relaxation: For each neighbor $v$ connected via road $e$:
    • If $e$ is BLOCKED: skip (edge cost is $\infty$).
    • Compute dynamic edge weight: $W(u, v) = \text{distance} \times \text{multiplier}$.
    • If $dist[u] + W(u, v) < dist[v]$: update $dist[v] = dist[u] + W(u, v)$, record $prev[v] = u$, and push $(dist[v], v)$ into priority queue.
  5. Termination: Terminate when destination is dequeued or queue is exhausted.
  6. Path Reconstruction: Backtrack from destination to source using $prev$ to form the route.

Python Implementation Snippet

def dijkstra(graph, source, destination):
    distances = {node: float("inf") for node in graph.nodes}
    distances[source] = 0.0
    previous = {node: None for node in graph.nodes}
    pq = [(0.0, source)]  # (cost, node)

    while pq:
        current_cost, u = heapq.heappop(pq)
        if u == destination:
            break
        for v, road in graph.get_neighbors(u):
            if road.status == "BLOCKED":
                continue  # Avoid severed link
            dynamic_weight = road.distance_km * road.traffic_factor
            tentative_cost = current_cost + dynamic_weight
            if tentative_cost < distances[v]:
                distances[v] = tentative_cost
                previous[v] = (u, road)
                heapq.heappush(pq, (tentative_cost, v))

    return reconstruct_path(previous, source, destination)
Time Complexity: $O((V + E) \log V)$ with Min-Heap Priority Queue
Space Complexity: $O(V + E)$ for Adjacency List and Distance Array
